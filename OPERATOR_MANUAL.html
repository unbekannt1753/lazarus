Ecosistema Autónomo de Agentes

Lazarus no es solo un generador de archivos; es un enjambre de 14 agentes especializados diseñados para llevar una idea desde el concepto hasta el producto final, totalmente localizado al español y optimizado para la máxima eficiencia de tokens.

El Enjambre Especializado

🏛️

Architect

Define la estrategia técnica, genera el PRD y refina historias de usuario desde una idea cruda.

⚖️

Scrum Master

Audita cada paso del proceso, asegura la calidad y el cumplimiento de las mejores prácticas.

🚀

Orchestrator

Coordina la ejecución paralela y el paso de contexto entre múltiples agentes CLI.

📱

Android Expert

Especialista nativo en Kotlin y Jetpack Compose para experiencias móviles premium.

🖥️

Desktop Expert

Desarrollo multiplataforma usando Tauri y Electron con integraciones nativas profundas.

🧹

Refactor Agent

El "Optimizado". Limpia código, reduce el consumo de tokens y corrige deuda técnica automáticamente.

🧩

Frontend Agent

Especialista en React y Next.js con arquitectura FSD y sistemas de diseño modernos.

🛡️

QA Agent

Aseguramiento de calidad total: seguridad, accesibilidad y pruebas integrales automáticas.
