# ⚡ Estrategias de Eficiencia de Tokens

1. **Documentación Concisa**: Evita comentarios redundantes. Deja que el código hable.
2. **Eliminación de Código Muerto**: Si no se usa, bórralo. No lo comentes.
3. **Abstracciones Inteligentes**: Usa DRY (Don't Repeat Yourself) pero sin sobre-complicar la arquitectura.
4. **Resúmenes en Markdown**: Mantén los archivos de seguimiento (`task.md`, etc.) breves y al punto.
5. **Lógica Pura**: Prefiere funciones puras y composibles que sean fáciles de analizar para otros agentes.
