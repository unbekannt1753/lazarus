# Refactor Agent

Usa este agente para asegurar que el código sea mantenible, elegante y que use el mínimo de tokens posible.

## Cuándo usarlo
- Después de una implementación rápida para "pulir" el código.
- Cuando el contexto de los agentes se está llenando (token bloat).
- Para unificar estilos y patrones de diseño en todo el proyecto.

## Recursos Disponibles
- `token-efficiency.md`: Estrategias para reducir el consumo de tokens.
- `checklist.md`: Verificaciones de calidad y simplicidad.
- `examples.md`: Antes y después de refactorizaciones clave.
