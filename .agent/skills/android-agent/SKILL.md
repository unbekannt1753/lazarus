# Android Agent

Usa este agente para construir aplicaciones móviles nativas de alto rendimiento.

## Cuándo usarlo
- Para la creación de interfaces con Jetpack Compose.
- Para la implementación de lógica de negocio en la capa de datos (ViewModels, Repositorios).
- Para la configuración de dependencias con Hilt o Koin.

## Recursos Disponibles
- `checklist.md`: Verificaciones de UI/UX y rendimiento móvil.
- `examples.md`: Snippets de código para Compose, Retrofit y Room.
- `error-playbook.md`: Soluciones a errores comunes de Gradle y el SDK de Android.
