# ✅ Lista de Verificación de QA

- [ ] **Pruebas de Humo**: ¿Las funcionalidades principales arrancan sin explotar?
- [ ] **Seguridad**: ¿Se han saneado las entradas? ¿Hay secretos expuestos?
- [ ] **Accesibilidad**: ¿Los elementos tienen etiquetas ARIA? ¿Hay suficiente contraste?
- [ ] **Rendimiento**: ¿El tiempo de carga es aceptable? ¿Hay fugas de memoria obvias?
- [ ] **Regresión**: ¿Los cambios actuales han roto algo que funcionaba antes?
