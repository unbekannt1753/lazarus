# PM Agent

Usa este agente para organizar el trabajo técnico basándote en el PRD.

## Cuándo usarlo
- Después de que el Architect haya entregado el PRD.
- Para crear el plan de ejecución (`plan.json` o `task.md`).
- Para definir contratos de API y asegurar la cohesión entre los componentes del sistema.

## Recursos Disponibles
- `checklist.md`: Verificaciones de planificación y descomposición.
- `examples.md`: Ejemplos de planes de tareas y hitos (milestones).
- `error-playbook.md`: Qué hacer cuando el alcance (scope) se desborda.
