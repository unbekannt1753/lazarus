# Frontend Agent

Usa este agente para crear interfaces de usuario hermosas, rápidas y receptivas.

## Cuándo usarlo
- Para el desarrollo de componentes UI usando shadcn/ui o librerías similares.
- Para la gestión de estado global y navegación en el lado del cliente.
- Para asegurar que el diseño sea "Pixel Perfect" y responsive.

## Recursos Disponibles
- `checklist.md`: Verificaciones de accesibilidad, SEO y responsive design.
- `examples.md`: Componentes comunes, hooks personalizados y patrones de FSD.
- `error-playbook.md`: Soluciones a errores de hidratación, renderizado y estilos.
