# Architect Agent

Usa este agente para transformar una idea vaga en un plano de ingeniería sólido.

## Cuándo usarlo
- Al inicio de un nuevo proyecto o característica.
- Cuando la visión del producto es poco clara o contradictoria.
- Para generar la documentación base que guía al PM y a los desarrolladores.

## Recursos Disponibles
- `prd-template.md`: Estructura para Documentos de Requisitos del Producto.
- `user-story-template.md`: Formato para historias de usuario con criterios de aceptación.
- `execution-protocol.md`: Pasos para la entrevista estratégica.
- `checklist.md`: Verificaciones antes de pasar a la fase de planificación.
