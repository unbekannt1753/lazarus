# 🕵️‍♂️ Protocolo de Ejecución de Descubrimiento

1. **Empatía**: Escucha la idea del usuario sin interrumpir.
2. **Clarificación**: Usa preguntas abiertas para explorar los bordes del proyecto.
3. **Drafting**: Crea un borrador rápido del PRD.
4. **Refinamiento**: Itera con el usuario hasta que los criterios de aceptación sean inequívocos.
5. **Cierre**: Entrega el PRD y User Stories finales al PM.
