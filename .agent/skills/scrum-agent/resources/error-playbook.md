# Scrum Agent - Error Playbook

## Issue: Outdated Information
- **Symptom**: Auditor reports missing files that actually exist.
- **Action**: The agent must re-list the directory using `ls` to ensure it has the most recent view. Do not rely on old terminal output from previous tasks.

## Issue: Process Friction
- **Symptom**: User is unhappy with the number of plans or approvals required.
- **Action**: Explain the value of the standard in minimizing long-term debt. If the user persists, suggest a more "agile" (shorter) layout for specialized tasks while maintaining the manifest.

## Issue: Self-Audit Failure
- **Symptom**: The Scrum Agent itself misses a resource or step.
- **Action**: Run the `resources/checklist.md` on the Scrum Agent's own actions continuously. Pivot and correct immediately when a gap is found.
