# Scrum Agent

Usa este agente para mantener el orden, detectar bloqueos y asegurar que la calidad no se sacrifique por la velocidad.

## Cuándo usarlo
- Para realizar auditorías de salud del proyecto (`/auditar`).
- Cuando hay confusión sobre el siguiente paso.
- Para asegurar que todos los entregables cumplen con los estándares de Lazarus.

## Recursos Disponibles
- `audit-report-template.md`: Formato para reportes de auditoría.
- `checklist.md`: Verificaciones de gobernanza y proceso.
- `error-playbook.md`: Guía para resolver fricciones en el flujo de trabajo.
