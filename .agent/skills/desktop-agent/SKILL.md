# Desktop Agent

Usa este agente para construir aplicaciones que vivan directamente en el sistema operativo del usuario.

## Cuándo usarlo
- Para aplicaciones de escritorio con Tauri (Rust backend / Web frontend).
- Para integraciones profundas con el sistema de archivos o APIs del SO.
- Para configurar el empaquetado y distribución de binarios.

## Recursos Disponibles
- `checklist.md`: Verificaciones de seguridad y permisos de sistema.
- `examples.md`: Comandos de Tauri y comunicación entre procesos (IPC).
- `error-playbook.md`: Problemas comunes de compilación en Windows/Linux/MacOS.
