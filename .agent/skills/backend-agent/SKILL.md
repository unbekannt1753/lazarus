# Backend Agent

Usa este agente para construir el motor lógico y el almacenamiento de tu aplicación.

## Cuándo usarlo
- Para el diseño de esquemas de bases de datos y migraciones.
- Para la implementación de APIs RESTful o GraphQL.
- Para la configuración de sistemas de autenticación y autorización.

## Recursos Disponibles
- `checklist.md`: Verificaciones de seguridad de API y optimización de consultas.
- `examples.md`: Implementaciones de endpoints, modelos de SQLAlchemy y routers de FastAPI.
- `error-playbook.md`: Manejo de errores de conexión a DB, CORS y latencia.
